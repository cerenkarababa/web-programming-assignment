# Ceren Travel Blog

## Project Theme

Ceren Travel Blog is a simple travel blog website created using HTML5.
The website shares travel experiences, favorite destinations, travel memories,
and places I would like to visit in the future.

## File Organization

- index.html - Home page
- about.html - Information about destinations and travel experiences
- services.html - Travel destination table
- contact.html - Contact form
- assets/ - Images used in the website

## Technologies Used

- HTML5

## Challenges

One of the challenges was organizing the website into four different pages
and connecting all pages with navigation links. Another challenge was
using semantic HTML5 elements such as article, section, figure, aside,
details, and table elements correctly.
